# 证小安 · 公证知识库问答

线上公证办理平台的知识库问答应用，支持四要素分析型问答（办什么公证 / 户籍在哪儿 / 在哪儿使用 / 用途是什么）。

## 功能

- 📚 结构化知识库：25 条公证事项，每条含四要素、价格、要求、材料
- ☑️ 对外/对内勾选：每条事项标记可否对当事人答复，前端可切换当事人/管理员视图
- 🤖 右上角模型选择器：DeepSeek / 豆包 / 智谱 / 通义多模型可选，支持免费额度模型
- 🧠 四要素分析：缺要素先追问，齐全后按「结论→依据→办理要素→材料→价格→下一步」输出
- 📋 各省报价表：31 个省市公证报价与公证方式
- 🔒 降级可用：未配置 API Key 时自动降级为知识库检索模式
- 🌍 **涉外国家判定**：识别问句中的国家/地区（含申根、欧盟等区域词），依据外交部《公约》缔约国名单（127 国）判定**单号/双号**以及**是否必须海牙认证**，并对非缔约国提示领事认证（双认证）
- 💡 **相关知识点兜底**：知识库无命中时不猜测，改为展示官方清单相关事项 + 相近条目差异 + 联网检索补充
- 🗣️ **口语词形归一**：「意向监护」等口语说法自动映射到官方规范术语「意定监护」
- ⏱️ **办理周期口径**：按各省实际口径回答（普通 3-5 工作日 / 涉外 10-15 工作日），严禁编造

## 静态版（GitHub Pages）

`weixin.html` / `index.html` 为**完全自包含的单页**（数据内嵌、零外部依赖），可直接静态托管，
无需后端即可提供知识库检索、涉外国家判定与相关知识点展示。

- 站点地址：<https://4sirfour.github.io/zhengxiaoan/>
- 入口：仓库根目录 `index.html`（由 `weixin.html` + 桌面端适配样式生成）

> **说明**：静态版不含 AI 模型分析、联网核实与图片识别——这些能力需要后端在线。
> 页内提示会引导用户到完整版。`build_weixin.py` 中的 `API` 常量即完整版后端地址。

重新生成入口页：

```bash
python3 - <<'PY'
src = open('weixin.html', encoding='utf-8').read()
desktop_css = open('desktop_css.txt', encoding='utf-8').read()  # 或直接内联
src = src.replace('</style>', desktop_css + '\n</style>', 1)
open('index.html','w',encoding='utf-8').write(src)
PY
```

## 运行

```bash
python3 server.py          # 默认 8000 端口
PORT=3000 python3 server.py
```

纯标准库实现，无第三方依赖。

## 配置

页面右上角「⚙️ 配置」填入模型 API Key（存于服务端本地 config.json，不入库）。
也支持环境变量：`DEEPSEEK_API_KEY` / `ARK_API_KEY` / `GLM_API_KEY` / `QWEN_API_KEY`。
