# 证小安 · 公证知识库问答

线上公证办理平台的知识库问答应用，支持四要素分析型问答（办什么公证 / 户籍在哪儿 / 在哪儿使用 / 用途是什么）。

## 功能

- 📚 结构化知识库：25 条公证事项，每条含四要素、价格、要求、材料
- ☑️ 对外/对内勾选：每条事项标记可否对当事人答复，前端可切换当事人/管理员视图
- 🤖 右上角模型选择器：DeepSeek / 豆包 / 智谱 / 通义多模型可选，支持免费额度模型
- 🧠 四要素分析：缺要素先追问，齐全后按「结论→依据→办理要素→材料→价格→下一步」输出
- 📋 各省报价表：31 个省市公证报价与公证方式
- 🔒 降级可用：未配置 API Key 时自动降级为知识库检索模式

## 运行

```bash
python3 server.py          # 默认 8000 端口
PORT=3000 python3 server.py
```

纯标准库实现，无第三方依赖。

## 配置

页面右上角「⚙️ 配置」填入模型 API Key（存于服务端本地 config.json，不入库）。
也支持环境变量：`DEEPSEEK_API_KEY` / `ARK_API_KEY` / `GLM_API_KEY` / `QWEN_API_KEY`。
